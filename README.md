# plan-translator-colab

Colab training for a small model that turns a short question into a JSON plan.

[Open in Colab](https://colab.research.google.com/github/fatihsokmen/plan-translator-colab/blob/main/train_colab.ipynb)

- `train_kaggle.ipynb`: the same run on Kaggle (File → Import Notebook, then Save & Run All).
- `train.py`, `predict.py`: training and prediction scripts.
- `data.tar.gz`: generated training and dev data, and test prompts (no answers).
